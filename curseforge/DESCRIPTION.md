# WhoDueling

**See who challenged you to a duel with one click.**

WhoDueling adds a small **Who dueled me?** button below the Blizzard duel request dialog in **World of Warcraft: Forever**. Click it to target the player who challenged you, then accept or decline the duel using Blizzard's usual buttons.

## Features

- A single, compact button that appears with a regular duel request.
- Exact targeting using the challenger's complete first name and surname.
- The button follows the duel dialog, hides during combat, and disappears when the request closes.
- Works on its own; your opponent does not need the addon.
- No configuration required.

## Compatibility

Built for **WoW Forever 1.60.1**, interface **16001**. Duels to the death are excluded. The player must be present and targetable by the game client.

The button reads **Who dueled me?** in every client language.

## Installation

Install WhoDueling for your **Forever** installation using the CurseForge app, or extract the ZIP's `WhoDueling` folder into your game's `Interface/AddOns` directory. Restart WoW after the first installation and enable the addon. Use `/reload` for updates while it is already loaded.
